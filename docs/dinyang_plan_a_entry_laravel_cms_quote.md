# 定陽企業官網 — 方案 A：入門版 Laravel 可更新官網（含產品案例展示）

> 文件用途：對內評估與對外報價基準  
> 版本定位：一切先從簡，先完成「可正式對外展示、可由後台更新、可導流 LINE、可上架產品案例」的企業官網  
> 不導入 CRM、不做完整詢價管理、不做 LINE API 推播、不做結構化產品規格庫

---

## 一、方案定位

本方案為第一階段入門建置，目標是先協助定陽企業有限公司建立一套可正式對外展示的企業官網，並提供基本後台讓公司可自行更新主要內容。

第一階段重點不是建立完整業務系統，而是先完成：

1. 公司門面更新
2. 產品服務與產品案例清楚展示
3. 手機版可正常瀏覽
4. 後台可更新基本內容（含產品案例上架）
5. LINE 官方帳號導流
6. 基礎 SEO 與網站上線

後續若網站上線後開始累積詢價，再依實際流程擴充詢價管理、LINE 自動通知、客戶管理或報價流程。

## 十一、給客戶看的簡版說法

第一階段建議先做「入門版 Laravel 可更新官網」，主要目標是先把公司網站門面、產品服務與產品案例展示、LINE 聯絡入口整理好，並提供後台讓公司可以自行更新 Banner、公司介紹、產品服務、產品案例、最新消息與聯絡資訊。

產品案例支援單層分類（如：客製線組、自動化設備用線、醫療設備配線等），每筆可上 1-3 張產品照與描述，方便客戶在前台依分類瀏覽。

這一階段不先做太複雜的 CRM、報價流程、LINE 自動推播或結構化產品規格庫，避免一開始預算過高、系統太複雜。等網站上線後，若開始累積詢價，再依照實際需求擴充詢價管理、LINE 自動通知、產品規格資料庫或客戶管理系統。

建議第一階段建置費用：

> **NT$88,000**

主機與網域等年度費用由公司自行申請與付款，預估約 NT$7,000 – 11,000 / 年。
